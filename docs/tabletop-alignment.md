# Tabletop 对齐 Casino 的实施契约

本文描述本轮已实现的 Casino 基础代码，供 Tabletop 独立迁移参考。两个插件继续独立安装；无需运行时依赖 Casino，也没有新增公共插件。Tabletop 源码未在本轮修改。

## 1. 消息键与参数

```java
Language.component("machine.stake-saved", "amount", amount); // 显示
Language.text("machine.stake-saved", "amount", amount);      // 日志/纯文本
```

- 使用固定消息键和 `{name}` 参数，不对中文原句或玩家名称做片段替换。
- 模板由 `ui.MessageText` 解析为 Component；普通参数直接插入文本，允许显式 Component 参数保留样式。不要解析参数，再把它拼回模板。
- 颜色、粗体等属于模板；动作由按钮描述中的 action 和代码回调决定。语言文件不允许 click/hover/font/动态查询标签。
- `&`、`§` 只在模板层兼容，颜色代码会重置装饰；新模板使用 MiniMessage。`Language.text` 不返回旧颜色码。
- Tabletop 迁移时保留现有语言/YAML 的备份与明确适配入口，不能把中文原句匹配继续当成主接口。旧词条如何映射需由 Tabletop 按实际菜单决定。

## 2. 语言文件与热重载

Casino 使用 `languages/en_US.yml`、`zh_CN.yml`，以 bundled English 定义键和参数集合。缺键允许回退，未知键、非字符串、错参数和错误样式报告文件与键。首次启动逐项回退；热重载遇到任意诊断则保持上一份完整语言。

`/3dcasino reload-language` 校验成功后切换 Language 修订号、清除旧菜单令牌，刷新实体文字。不会重建机器、修改模型矩形或终止游戏。忙碌控制器在安全刷新点更新动态状态。Tabletop 应接入自己的房间/棋盘文字刷新，保留进行中的棋局。

## 3. 原生 Dialog 描述与外部布局

`ui.MenuView` 包含 Component 标题、正文列表、文本输入、按钮、关闭按钮和列数。构造阶段校验输入 ID、默认值长度、宽度、列数和重复 ID；列表不可变。

Casino 的 `PaperMenus` 直接渲染 MenuView。Tabletop 保留外部 YAML 布局的方式应为：

1. 在加载阶段把 YAML 校验并适配到 MenuView。
2. 文本字段从固定消息键或已校验模板产生 Component。
3. action 字段只映射到代码注册的业务动作；不要把显示文案当 action。
4. 展示阶段复用同一个 Dialog 渲染器，不来回序列化 YAML。

Casino 本轮没有新增外部菜单布局配置，不能把这份适配建议理解为已存在的 YAML API。

## 4. 回调生命周期

`ui.MenuSessions<T>` 使用玩家 UUID + 随机令牌、单调时钟和单次消费。重新打开替换旧会话，消费前核对令牌；错误玩家或旧令牌不会吃掉当前会话。定期清理过期会话，退出/重载/停止时清理。

Casino 保持五分钟过期。Tabletop 可保留既有两分钟策略。执行时仍要检查主线程、插件启用、菜单开关、当前权限以及房间/机器存在、归属、世界、距离和忙碌状态。令牌有效不能代替业务校验。

## 5. 显示实体与文字

`LabelLayout` 在已有矩形内估算可见字符宽度、继承粗体、多行与宽字符；长文本截断为最多两行，极窄区域继续缩小省略号。默认字体是近似度量，不能保证自定义客户端字体像素精确。

`VanillaDisplay.sync` 先处理模型/语言变化，再跳过无位置、姿态、发光变化的子实体遍历。原有动画、材质切换和零缩放恢复仍有回归覆盖。按压姿态只在按下/释放时写入。Tabletop 可以借鉴这个状态比较方法，保留自己的地图显示、棋子动画、观战和落点提示。

## 6. 存储与性能边界

保留各自存档格式和恢复语义。Casino 的布置文件不保存进行中的免费练习回合；经济对局记录仍由独立持久化服务管理。模型记录构造器校验引用、边界和旋转，读坏文件不会顺手覆盖原文件。

本轮无变化同步回归验证：200 次调用不再遍历子实体，发生变换后仍会遍历。区块恢复只测了 10/100/1,000/10,000 条不存在世界记录的扫描，不能代表实体生成或真实区块加载成本；没有据此增加复杂索引，也没有宣称客户端 FPS 提升。

## 7. Tabletop 验收清单

- 玩家名包含 `<red>`、`&c`、花括号时仍显示字面值。
- 中英文、缺键、错误 YAML、无权限和失败热重载均有行为测试。
- 重开、退出、超时、重载后的旧按钮无效；重复点击只执行一次。
- 进行中棋局、历史、观战和房间恢复保持原语义。
- 长标题、按钮、提示、粗体与中文模型标签有真实运行预览和客户端验收。
- 独立 JAR 测试不安装 Casino。公共库等出现真实重复需求后再提取，并构建时打入各自 JAR。
